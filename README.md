專題系統 IPO 模組分析器
系統概述
1.1　工具用途
「專題系統 IPO 模組分析器」是一個瀏覽器網頁工具，協助大一非資訊系學生分析並改進自己的 Python 專題程式碼。它運用 AI 將學生的程式碼自動拆解為三個經典模組 ─ 輸入 (Input)、處理 (Process)、輸出 (Output)，並針對每一模組給出優化建議與可執行的改寫版本，最後可下載完整的學習資源。
整套流程設計為五個依序進行的步驟，每一步皆有明確的視覺指引與容錯機制。即便 AI 回應失敗，工具仍提供「手動模式」與「除錯面板」讓使用者不至於卡關。

1.2　IPO 三模組架構
IPO 是資訊系統的基本三段結構，任何程式都可拆成「資料怎麼進來、怎麼處理、怎麼出去」這三個階段。本工具即以此為核心架構分析學生程式碼，並針對每一階段給出最常見的初學者改進方向：
●	INPUT 輸入模組　─　改用 ipywidgets 製作互動介面，取代寫死的變數賦值
●	PROCESS 處理模組　─　把長段運算拆成可重用的 function，加 docstring 與行內註解
●	OUTPUT 輸出模組　─　用 matplotlib 繪製圖表，取代單純的 print 文字輸出

1.3　學習目標
學生使用本工具完成一次完整分析後，可達成下列學習目標：
1.	理解 IPO 三模組結構，並能將任意 Python 程式套用到此架構
2.	認識三項初學者程式優化的核心技術 ─ ipywidgets、function、matplotlib
3.	體驗 AI 輔助程式設計的工作流程，了解 API 金鑰、提示語、回應解析的概念
4.	產出可直接放入專題報告的圖文資料（PDF / 圖片 / Jupyter 筆記本）
給授課老師
建議在課堂上先讓學生跑一遍完整流程，確認每位學生能拿到 Gemini API 金鑰並成功完成首次分析，再讓他們對自己的專題程式作分析。整套流程通常可在 30 分鐘內熟悉。
